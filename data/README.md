# Входные данные

В `sample/` приложена маленькая система 7 × 5 для проверки формата. Основные измеренные наборы воспроизводятся генератором из `src/data.py` по параметрам `configs/local.json`.

Формат каждого каталога:

- `A.npy` — матрица float64 размера M × N;
- `b.npy` — вектор длины M, b = A @ x;
- `x.npy` — известный вектор решения длины N;
- `Atb.npy` — проверочный вектор A.T @ b;
- `manifest.json` — размеры, seed и параметры генерации.

Формат NumPy выбран вместо текстовых файлов из прошлых лабораторных, чтобы не раздувать исходные наборы объёмом в десятки ГБ. Матрица генерируется блоками, сохраняется в `.npy` и читается через memory mapping. Это уменьшает потребность генератора в RAM, но не отменяет память, необходимую рабочим процессам для их локальных блоков.
